6. Run info registers and identify registers holding recognizable parts of the program

    Answer:
    Several registers contain values that can be connected to the program:

    - rbx = 0x7fffffffcfa8
    This is the same address as argv, so rbx is holding the argv pointer.

    - rdi = 0x3
    rdi contains 3. On x86-64 Linux, rdi is used for the first function
    argument, which matches the call recur(3).

    - rsi = 0x64
    0x64 is 100 in decimal, which matches the 100-byte size used by
    malloc(100) in map.c.

    - rip = 0x5555555551a9 <main+64>
    rip is the instruction pointer and shows the location in main where
    execution will continue.

    - rbp = 0x7fffffffce80
    rbp is the base/frame pointer for the current stack frame.

    - rsp = 0x7fffffffce50
    rsp is the current stack pointer.
