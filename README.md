# Linux, Shell, and C Lab

## Overview

This repository contains my work for the Ubuntu Linux command line,
shell scripting, and C programming lab.

## Structure

- `command-line/` - Linux command-line exercises and logs.
- `shell-scripts/` - Bash scripts and automation.
- `c-programs/` - C programming exercises and programs.

## Testing and Running

### Command Line
I practiced Linux navigation, file management, permissions,
pipes, redirection, networking, aliases, and package management.

### Shell Scripts
I created and tested easy-greet.sh, file-check.sh,
and file-count.sh.

### C Programs
I compiled and tested C programs using gcc, including
add.c, factorial.c, and contacts.c.

### Integration Project
project.sh compiles and runs contacts.c, creates a backup,
and writes a timestamp to project-log.txt.

## Challenges and Learnings

During the lab, I learned how Linux permissions, shell scripts,
Git, and C compilation work together.

I encountered a missing ping command and installed iputils-ping.
I also encountered a permission denied error with a shell script
and fixed it using chmod +x.

I also learned how relative file paths affect shell scripts
when accessing files in other directories.# linux-c-lab
